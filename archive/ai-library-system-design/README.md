# AI Library: System Design (archived snapshot)

A verbatim copy of the AI Library's **System Design** course, kept here so that nothing is lost while the Guide and the library are restructured, and so the content can be reconstructed later.

- **Source:** the AI Library repository, `notes/system-design/markdown/` and `notes/system-design/_subject.json`
- **Library commit:** `311adcb` (refreshed 2026-10-20)
- **Contents:** all 29 numbered chapter files plus `Resources.md` (including chapters 11-14, 17-20 and 22), and the subject metadata

## Notes

- These are plain Markdown files, unchanged byte for byte. They include the library's ` ```mermaid ` and ` ```venn ` diagram blocks.
- The ` ```venn ` blocks are drawn by `assets/venn.js` in this repository (the same file the library uses).
- Nothing in `tools/build_pages.py` reads this folder; it only builds from `volumes/` and `roadmap.md`.
- Pages generated from this content (HTML, images) are not copied; they can be regenerated with the library's `scripts/build.py`.
